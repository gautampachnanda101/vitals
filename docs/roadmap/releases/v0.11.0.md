# v0.11.0

[docs](../../index.md) / [Roadmap](../index.md) / **v0.11.0**

**Status**: Released 2026-10-12. Binaries on the
[GitHub Release](https://github.com/gautampachnanda101/vitals/releases/tag/v0.11.0);
`brew upgrade vitals` picks it up automatically.

## Scope

This release introduces native deep disk usage analysis, elevated disk usage detection,
context-aware memory diagnostics for buffer- and cache-heavy runtimes, and resilience
improvements for the local web dashboard.

- [x] [014 — Native deep disk usage analysis](../items/014-native-disk-analysis/)
  — `vitals disk --scan`: recursive directory ranking and top regular files summary
  with bounded runtime, memory-bounded ranking, and cooperative cancellation.
- [x] **Interactive dashboard disk exploration** — `/disk` features interactive
  drill-down, rescan, SVG donut visualization, and bounded LRU caching.
- [x] **Elevated disk warning** — `doctor` detects constrained disk headroom
  (≥80% used or <50 GB free headroom) with actionable next steps.
- [x] **Context-aware memory diagnostics** — memory growth analysis evaluates
  system-wide RAM and swap pressure and distinguishes normal KV cache / buffer pools
  in runtimes like `llama-server` from memory leaks.
- [x] **Dashboard advice commentary resilience** — protected advice page from
  auto-refresh script cancellation, added instant cache peeking, client fetch
  timeout fallback, and background disk scanning context for LLM advice.
- [x] **Schema bump** — `--json` schema **1.7.0** (additive disk scan and findings).
