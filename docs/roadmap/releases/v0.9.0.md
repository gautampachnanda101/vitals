# v0.9.0

[docs](../../index.md) / [Roadmap](../index.md) / **v0.9.0**

**Status**: Released 2026-09-06. Binaries on the
[GitHub Release](https://github.com/gautampachnanda101/vitals/releases/tag/v0.9.0);
`brew upgrade vitals` picks it up automatically.

## Scope

- [x] [008 — `vitals heal`](../items/008-heal-command/) — apply a
  finding's own remedy, previewed and confirmed, from a compile-time
  allow-list. Non-automatable findings stay printed instructions.
- [x] [011 — Console at-a-glance view](../items/011-console-at-a-glance-view/)
  — `vitals view` (and bare `vitals` on a TTY): a verdict-first,
  single-screen terminal layout of every resource plus the heaviest
  processes.
- [x] [012 — Per-resource consumers: the deeper numbers](../items/012-disk-consumers-detail/)
  — per-process disk I/O rate on `vitals disk` and the dashboard
  (Linux/Windows); a real macOS per-process energy reading on
  `vitals power` and the dashboard, replacing the CPU estimate.
  Per-process network bandwidth documented as not achievable with the
  current dependency.
- [x] [013 — Local container & Kubernetes awareness](../items/013-container-runtime-awareness/)
  — `vitals containers`: a read-only Docker Engine-API client (stdlib
  only, incl. the Windows named pipe) and a loopback-only `kubectl`
  handoff. `doctor` findings for OOM-kills, `CrashLoopBackOff`, restart
  loops, failing healthchecks, and container-VM memory the host process
  list can't see. `--json` schema **1.5.0** (additive).
- [x] Dashboard auto-refresh — read-only pages re-fetch and swap in
  their content every 10 s while the tab is visible; an on/off toggle,
  remembered per browser. Clean and Duplicates opt out (they hold
  Preview state).

## Also since v0.8.0

- Windows named-pipe Docker via a build-tagged `github.com/Microsoft/go-winio`
  (never in a macOS/Linux build) — the second, narrower exception to
  "one dependency" (see `AGENTS.md`).
- `vitals containers --runtime docker|kubernetes` for a kind/k3s host
  where both runtimes are local at once.
- A path-scoped `containers-integration` CI workflow: a real Docker
  daemon and a real `kind` cluster, `vitals` run as the compiled
  binary asserting detection and the findings.

## Not in this release

- The 011 console-view `containers` panel — it needs `QuickAssess` to
  carry containers, which trades against 011's no-probe speed model.
- Container `RestartCount` trend history; k8s nodes/events/deployments;
  `internal/tools` registry rows for `docker`/`kubectl`.
