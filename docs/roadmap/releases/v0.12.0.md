# v0.12.0

[docs](../../index.md) / [Roadmap](../index.md) / **v0.12.0**

**Status**: Released 2026-10-17. Binaries on the
[GitHub Release](https://github.com/gautampachnanda101/vitals/releases/tag/v0.12.0);
`brew upgrade vitals` picks it up automatically.

## Scope

A design and polish release: the dashboard's new look, licence
compliance for everything shipped in the binary, a more readable CLI,
and fixes found by checking real pages and real CI runs.

- [x] **Dashboard theme** — matches the homebrew-tap site in light and
  dark, follows the OS setting with a one-click override, and is built to
  WCAG 2.2 AAA (≥7:1 text contrast, 44 px targets, skip link, visible
  focus, reduced motion). Space Grotesk and IBM Plex Mono are embedded,
  so it still renders identically offline. Narrow screens get a
  scrolling top nav.
- [x] **Container VM disk and engine storage** — `vitals containers`, the
  Disk page and `doctor` show Docker Desktop / WSL2 virtual-disk size
  (logical and physical) and the engine's images / containers / volumes /
  build-cache breakdown.
- [x] **`vitals licenses`** — every third-party notice (Go standard
  library, compiled-in modules, fonts, icons) is embedded in the binary
  and printed by this command; release archives also carry `LICENSE` and
  `THIRD_PARTY_NOTICES.txt`, and CI fails if that file goes stale.
- [x] **Coloured help** — commands, flags and examples are highlighted;
  the flag column fits the longest flag.
- [x] **doctor** — a shared storage pool (macOS `/` and
  `/System/Volumes/Data`) is reported once instead of twice; the
  container probe is hard-bounded so a slow Docker service can't stall
  it.
- [x] **Fixes** — Clean / Duplicates keep their destructive buttons hidden
  until a preview; the Disk page no longer prints raw HTML in the VM disk
  row; dark-mode chart labels are legible; long paths stay inside disk
  tables.
- [x] **Schema bump** — `--json` schema **1.8.0** (additive container VM
  disk and storage fields).
