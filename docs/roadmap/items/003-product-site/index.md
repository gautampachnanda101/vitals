## What

A static, public marketing/docs page: install instructions, a feature
tour, the competitive comparison table from the persona review, links out
to the user guide and the GitHub repo.

## Why

Unlike the dashboard, this page has no dependency on any other roadmap
item and is the only deliverable in this whole plan that can reach a
non-technical visitor before they ever run a command. The original draft
plan sequenced this third, behind the dashboard and write actions — the
product-manager review that shaped this roadmap corrected that; see the
design doc §7.
