# vitals

A single static binary that names the one resource constraining your
machine right now and the exact command to fix it — cross-platform system
diagnostics with cross-resource correlation and local/cloud LLM advice, on
top of the same data htop/btop/glances already read.

This site is generated from the same Markdown that ships in the repo and
inside the binary itself (`vitals guide`) — nothing here is written twice.

## Start here

- **New to vitals?** [User guide](user-guide.md) — every command, with
  runnable examples. The same content `vitals guide` prints in a terminal
  and `vitals guide --web` renders in a browser.
- **Contributing or reviewing a change?** [`AGENTS.md`](https://github.com/gautampachnanda101/vitals/blob/main/AGENTS.md)
  in the repo root — build/test/lint commands, non-negotiable conventions,
  and how this repo runs its roadmap and review process.
- **Curious how a specific feature was designed, or what's next?**
  [Architecture](architecture/design.md) and the [roadmap](roadmap/index.md).
