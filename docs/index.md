# vitals

Part of the [vitals](https://github.com/gautampachnanda101/vitals) repository — this is the docs home.

A single static binary that names the one resource constraining your
machine right now and the exact command to fix it — cross-platform system
diagnostics with cross-resource correlation and local/cloud LLM advice, on
top of the same data htop/btop/glances already read.

This site is generated from the same Markdown that ships in the repo and
inside the binary itself (`vitals guide`) — nothing here is written twice.
